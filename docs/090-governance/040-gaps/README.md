- [Account lifecycle / identity gaps](070-account-lifecycle-and-identity.md)：User profile、closure、provider unlink、recovery/transfer 的 current/future 邊界。
- [Workforce gaps](060-workforce.md)：Organization／Employment／Calendar／Schedule 尚未落地、Attendance employment-scope 接續與完成條件。
