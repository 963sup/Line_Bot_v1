- 尚未交付完整 2.11 fixture、Estimate calculation、Payment、Reversal、owner direction full reporting。
- 遠端 migration、真 PostgreSQL 雙連線競爭、LINE 手機、業務簽核仍未完成。

本機瀏覽器與執行證據由 [Acceptance evidence](../../090-governance/060-acceptance/010-acceptance-evidence.md) 導覽；舊完整基線保留於其 `090-history/`。

## 2. 判定方式

| 狀態 | 使用條件 |
| --- | --- |
| 通過 | 全部驗收條件符合，且有版本、環境、日期與可重現證據；需要業務簽核者已簽核。 |
| 待驗證 | 規格或產物已有，但證據不足。 |
| 未交付 | 尚未提供該產物／實作。 |
| 未通過 | 已驗證且不符合；需連結 issue／修正與複驗。 |
| 不適用 | 只用於條件式項目，需記錄理由與決策者。 |

文件、算術、程式測試、環境運行與業務簽核分開判定。

## 8. Web Container v0.9 追加驗收

這些是 Web 架構演進條件，未併入既有 48 個 D/F/C/A/P ID，避免把目標 presentation 誤算成第一段已完成。

- W01：`/sap` 與 `/sap/projects` 不再是相同頁面語意。
- W02：`/sap/layout.tsx` 提供 SapContainer，project routes 不再逐頁重建相同 SAP navigation。
- W03：`/sap/projects/[projectId]/layout.tsx` 保留 project context，deep link 可正確恢復。
- W04：至少 20 project fixture 下，Projects searchable；sidebar 不永久列舉全部 projects。
- W05：mobile 不出現 SAP persistent sidebar 與 global fixed navigation 疊加；desktop 可由同 nav model render sidebar。
- W06：Project Switcher 切案後不殘留前一 Project 私有資料；後端 authorization 仍為 authority。
- W07：`/sap/work` 若交付，write action 回到 document owner，不新增 generic approvals engine。
- W08：若採 Parallel Routes，每個 slot 的 hard reload/default fallback/back-forward/deep-link 有證據。

## 9. 代表 fixture 與必測反例

代表 fixture 數值由 [雛形業務規則](030-prototype-business-rules.md) 擁有。至少要覆蓋：

- Budget 120,000、Subcontract 100,000 後剩餘 20,000；額外 20,000.01 Contract approval 拒絕；
- Estimate periods 40/50/10 的 G/R/D/N；
- Partial Payment 10,000 + 18,000；
- request 61 超 Contract remaining 被拒絕；
- excess Payment 0.01 被拒絕；
- concurrent same version only one success；
- cross-project direct API access 拒絕；
- third-period Payment + Estimate reversal 回復 83,000 / 9,000 / 2,000 / 10,000；
- 0.125 × 10.04 得 1.26，再一個 0.125 的累計差額是 1.25，總額 2.51；
- success response lost 後以同 requestId readback/retry 不重複效果。
