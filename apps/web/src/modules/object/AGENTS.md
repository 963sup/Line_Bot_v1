# Resource Web surface

`/{login}/{repository}/objects` presents the Resource owner contract. Repository locators only
select current scope; verified LINE identity maps to an active User and every read/write is
authorized again by the owning package. Resource, Resource Type and Resource Relationship remain
`@line_bot_v1/resources` facts.

The browser retains an unresolved command only for exact retry with the original request ID,
payload and expected version. Identity/session changes clear private state. Content is rendered
as escaped plain text. Cross-context references remain owned by their consumer.

The engineering panel owns quantity forms, per-level structure navigation and location/type totals.
It consumes Resource public DTOs and the existing authenticated request/retry lifecycle; business
allocation rules and totals remain in the Resource package. Measure creation is an ADMIN projection.

The collection consumes the Resource-owned per-level tree projection. Disclosure controls expand children;
row plus buttons create independently classified INCLUDES children without quantity through the existing
pending-command lifecycle. Classification management and root creation are collapsed disclosures.
Archived ancestor context never changes structural parenthood. Session loss unmounts all private branches.

Within one mounted collection, up to 32 recently read branch pages and their observed versions may
survive disclosure collapse. Cache scope includes actor, Repository and archive filter. Refresh and
successful mutations invalidate snapshots through the existing refresh generation; collapsed branches
reload only when reopened. Identity/session and page lifecycle invalidation still clear private state.
