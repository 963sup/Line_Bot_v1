# Supabase operation scripts

- Scripts separate schema source/rebuild, local verification, remote reconciliation and remote mutation; a successful local check never proves remote convergence.
- `schema-source.mjs` owns reading ordered declarative SQL, `schema-local.mjs` owns local rebuild, `remote.mjs` owns `prepare|plan|sync|verify` reconciliation semantics, and `postgres.mjs` owns SQL execution helpers. Do not hide provider mutation behind a generic helper or workflow shell block.
- Remote operations require exact project identity, explicit target, preconditions, bounded transaction/timeout, least-privilege connection, post-write readback and reconciliation evidence.
- Preserve current schema authority in `supabase/schemas/`; migration history remains replay/recovery evidence and must not silently replace the current source.
- `prepare` is additive preserve-data expansion/preflight only: it may lock, validate, backfill from explicit evidence and add current-compatible surface, but it must not drop/rename legacy authority, guess business metadata or authorize destructive contract. Automatic `Release` and manual `Supabase Replace` both run `prepare` before authorized `sync --allow-destructive`; Production Web promotion remains a later Release responsibility after database readback. Both retain target checks and post-write readback.
- Failure after an external write is an unknown result until independently read back; never retry with a new request identity without owner-specific idempotency and reconciliation.
- `.artifacts/supabase-remote/plan.sql`, `verification.sql`, `migration-history.before.txt`, `migration-history.after.txt` and prepare JSON are transient operation evidence. Do not hand edit or commit them; if required evidence for the operation is missing, the run does not support a remote convergence claim.
- Changes to remote classification, target checks, artifact shape, prepare behavior or release assumptions need focused `scripts/supabase/*.test.mjs` coverage; update workflow/tooling contracts when their assumptions are affected.
